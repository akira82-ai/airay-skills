⚠️ 铁律：实测一票否决。犀利是结论的自由，扎实是证据的纪律——狠话随便说，每句必须钉着实测细节；没实测的事实点一律不进稿。
🎯 北极星指标：time-to-decision。对外只有一句话——"30 秒帮你省 30 分钟"。判定结构固定：人群 × 场景 × 能接受的代价。

A · 单期生产流（每 Vol.n 跑一遍）

1选品 磊叔

  • 来源：GitHub 热榜 / X 时间线 / 群友点题 / 上期评论区
  • 动作：丢我 产品名 + GitHub 地址
▼

2评测前指引 我 · 模式 B

  • 全网 + X 搜集：大家吹哪几点 / 骂哪几点 / 竞品锚
  • 产出《试用指引》：5~8 个实测动作 + "别人没测过的角度"提示（给 20 年经验留发挥空间）
  • 可选：改成预告帖先发 X
▼

3真实实测 磊叔 · 不可替代

  • 按指引试：掐表、复现骂点、验证吹点
  • 独有视角：凭 20 年经验找别人看不见的坑和用法
  • 记口语笔记 + 截图（1 主图素材 + 3~4 明细图）
📤 回传：笔记 + 截图（细节就是指纹：版本号、报错原文、第几个文件翻车）
▼

4初稿生成 我 · 模式 A

  • 三方对照（宣传/别人说/你实测）找落差，放大你的独有观察
  • 按《磊叔语言风格卡》出稿：标题行 → "磊叔说"5 档 → 自然段落约 200 字
  • 每句必须能改变读者一个动作，否则删
↩ 缺截图 → 我列清单问你要，绝不用网图
▼

5润色 + 事实核对 磊叔 · 发布闸门

  • 按自己的腔调做文字优化（真实感的最后兜底）
  • 逐句核对事实 + 确认"磊叔说"档位
↩ 有不符 → 打回 ④ 重写，过不了闸不发
▼

6四处分发 一次生产 · 多平台复用

  • X：主帖（自包含）+ 证据跟帖 + 互动钩子
  • 小红书：图 + 文 ／ 公众号：短内容
  • 抖音：同稿改口播脚本，配图当视频素材
  • 转群："XX 好不好用？看磊叔 100 字评测第 n 期"
▼

7复盘收题 我整理 · 磊叔回评

  • 发帖后 1 小时高频回评；群友反馈整理（他们踩的坑可复现进下期）
  • 收下一期点题 + 数据复盘（哪档话术/哪类产品互动高）
🔁 第 7 步收到的点题 → 回到 ①，开启 Vol.n+1

B · 三条业务回路（让这件事越做越值钱）

👥 社群回路
内容转群 → 群有点题权 + 补坑素材 → 下期选题更准 → 群有固定节目不掉活跃 → 内容
📚 判定库回路
每期入同尺度判定库 → 第 1 期是观点，第 100 期是标准 → "装前先查磊叔说" → 影响力反哺选题与话语权
🏷️ 品牌回路
100 问 + 100 字双品牌 → 现有粉丝盘互导（X 1k / 公众号 2w+ / 抖音 1w+）→ X Premium 一年为窗口期冲 X 涨粉
「100 字评测：你读的是 100 字，我押的是 20 年。」 后期变现走信任变现（佣金 / 选型咨询），商单慎接——档位可信度就是全部资产
