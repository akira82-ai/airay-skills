# 阶段 3：强规则检查修复

读取 `03-airay-style.md`，输出 `04-final.md`。

目标：做最终清理，确保输出可以通过最高优先级规则。

## 必须清理

严禁输出“前半句用 `不是` 否定、后半句用对应转折词纠正”的二段式对照句。

无论这个结构出现在同一句、相邻两句、跨标点、跨换行，还是被拆成短句，只要表达功能仍然是“先否定一个说法，再用转折纠正”，都必须改掉。

## 允许修改

- 拆句。
- 换句式。
- 调整局部表达顺序。
- 改成直接判断。
- 改成递进解释。
- 改成具体问题描述。

## 禁止修改

- 不要改变事实。
- 不要改变立场。
- 不要新增信息。
- 不要删除重要信息。
- 不要重组全文。

## 输出前

写入 `04-final.md` 后，必须运行：

```bash
python scripts/check_constraints.py work/YYYYMMDD-HHMMSS/04-final.md
```

如果失败，修复 `04-final.md` 相关句子，并再次运行检查。

只输出最终正文，不要解释。
