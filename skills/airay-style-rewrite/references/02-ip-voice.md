# 第 2 步：IP 语气初改

目标：先解决“是谁在说话”。这一阶段把文本拉到 AIRay/IP 的表达方向里，不急着做机械去 AI。

AIRay/IP 语气的核心不是口癖，而是判断方式：

- 更直接。
- 更有偏好。
- 更敢下判断。
- 更少中立说明。
- 更有纠偏感。
- 情绪更明确，但不空洞煽动。

## 工作内容

- 把中立说明改成明确判断。
- 把温吞表达改得更直接。
- 把泛泛赞美改成具体好处。
- 把模糊否定改成具体问题。
- 把“看起来不错”改成“为什么值得看”。
- 把“存在不足”改成“哪里真的不对劲”。
- 保留原文观点，但提高表达的主观密度。

## 规则

- 不要把文本改成报告。
- 不要为了显得有态度而乱骂。
- 不要机械添加 `ok`、`good`、`明白不`。
- 不要所有段落都情绪拉满。
- 不要把 AIRay 语气理解成固定口头禅。
- 重点是判断力，不是装腔。

## 常用动作

- 中立描述 -> 个人判断。
- 抽象评价 -> 具体问题。
- 平滑表达 -> 带一点锋利度。
- 泛泛推荐 -> 说明为什么值得用。
- 泛泛反对 -> 指出到底哪里不舒服。

## 阶段文件要求

`03-ip-voice.md` 必须包含：

- 改写后的 AIRay/IP 初稿。
- 底部 `INTERNAL CHECKLIST`。

内部检查区必须确认：

- 已读取 `02-source-lock.md`。
- 已读取本 reference。
- 已保留原文核心意思和硬事实。
- 已提升主观判断密度。
- 未机械添加口头禅。

## 对比示例

AI 腔：

> 这款产品具备一定创新性，但仍存在体验上的优化空间。

AIRay/IP 初改：

> 这东西有点意思，但我现在还不太信。它不是没亮点，问题是你真的用起来，会发现最麻烦的那一步还在。

AI 腔：

> 该功能可以帮助用户提升内容生产效率。

AIRay/IP 初改：

> 这个功能真正有用的地方，是它少让我来回复制粘贴。别小看这一步，写东西的人最烦的就是这种碎操作。
